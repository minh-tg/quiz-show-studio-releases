# Quiz Show Studio downloads

Installers and update files for [Quiz Show Studio](https://minh-tg.github.io/quiz-show-studio-releases/), a desktop app for hosting game-show style quiz nights with a host screen and an audience screen.

- **Download:** see [Releases](https://github.com/minh-tg/quiz-show-studio-releases/releases/latest) for Windows and macOS.
- **Website, pricing and free sample boards:** https://minh-tg.github.io/quiz-show-studio-releases/

This repository holds release files and the website only. Installed copies of the app check it for updates.
